## Visão geral do projeto

**Adote um Amigo** é uma aplicação web educativa que simula o processo de adoção responsável de animais (cães, gatos ou outros pets). O objetivo é permitir que usuários explorem fluxos típicos de adoção – listagem, filtros, solicitação, histórico, cancelamento, login simulado, painel administrativo e cadastro de animais – tudo executado no navegador, sem necessidade de backend.

## Funcionalidades

Todas as funcionalidades descritas abaixo foram implementadas, testadas e validadas na versão atual:

- Listagem e filtros de animais  
- Solicitação de adoção  
- Histórico de adoções e opção de cancelamento  
- Login simulado  
- Painel administrativo  
- Cadastro de novos animais  
- Regras de prazo e disponibilidade

## Começando

1. Clone este repositório:  

   ```bash
   git clone https://github.com/restoffkaua08-afk/adote-um-amigo.git
   ```

2. Abra o arquivo `index.html` em seu navegador preferido.  
3. Não é necessária nenhuma dependência ou instalação adicional.

## Garantia de qualidade

- Verifique a responsividade em diferentes tamanhos de tela.  
- Confirme que os fluxos principais (listagem, adoção, cancelamento, login) funcionam sem erros no console do navegador.  
- As funcionalidades já entregues foram validadas manualmente antes de cada commit.
