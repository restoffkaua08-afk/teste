## Descrição  

Landing page educacional que simula a apresentação de um serviço de streaming musical. O projeto foi desenvolvido em dupla e utiliza apenas tecnologias web nativas (HTML, CSS e JavaScript).  

---  

## Demonstração (em breve)  

> Uma demonstração pública será publicada assim que o ambiente de hospedagem estiver configurado. Enquanto isso, basta abrir o arquivo **`Spotify-Clone/index.html`** em um navegador para visualizar a aplicação localmente.  

---  

## Visão geral do projeto  

Spotfy tem o objetivo de mostrar, de forma interativa, como seria a interface de um serviço de streaming musical. Não há backend nem integração com APIs externas neste momento; trata‑se de um frontend estático pensado para aprendizado e experimentação.

## Funcionalidades  

- Hero promocional  
- Menu responsivo  
- Contadores animados (Intersection Observer)  
- Cards de recursos e planos  
- Carrossel de imagens  
- FAQ interativo  
- Simulação de newsletter  
- Animações baseadas em scroll

## Começando (Getting Started)  

1. Clone o repositório  

   ```bash
   git clone https://github.com/restoffkaua08-afk/spotfy-streaming-musical.git
   ```  

2. Abra o arquivo `Spotify-Clone/index.html` em seu navegador preferido.  

> **Observação:** O projeto não depende de nenhuma biblioteca ou ferramenta externa.
